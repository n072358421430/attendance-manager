# 출결·장려금 매니저

**[▶ 바로 사용하기](https://n072358421430.github.io/attendance-manager/attendance-manager.html)**

동아일보 AI Lab의 K-디지털 트레이닝(KDT) 과정인 「AI Agent를 활용한 디지털 미디어 콘텐츠 Innovator」(AI에이전트 기반 AI 자동화 시스템 구축 실무과정) 5기 훈련생이 자신의 출결 상태를 직접 관리하는 웹 앱입니다.
지각·조퇴·외출·결석·휴가를 입력하면 과정 규정에 맞춰 출석률을 계산하고, 이번 차수에 훈련장려금을 받을 수 있는지와 수료·제적 기준까지 남은 여유를 보여줍니다.

> KDT(K-디지털 트레이닝)는 고용노동부가 주관하는 디지털 분야 직업훈련 사업으로, 국민내일배움카드로 수강합니다.
>
> 이 앱은 이 과정의 학사규정과 동아 AI Lab AI Agent 5기 과정운영팀 안내를 바탕으로 만든 개인 관리용 도구입니다. 실제 출결은 고용24 앱 QR 체크와 줌 접속 기록으로 처리되므로, 판정이 애매한 경우 반드시 동아 AI Lab AI Agent 5기 과정운영팀에 확인하세요.

## 사용 방법

1. `attendance-manager.html`과 `form_template_b64.js`를 **같은 폴더**에 내려받습니다.
2. `attendance-manager.html`을 크롬 등 브라우저로 엽니다. 설치나 서버 실행은 필요 없습니다.
3. 출결 대시보드에서 지각·조퇴·외출·결석·휴가가 있었던 날만 등록합니다. 등록하지 않은 훈련일은 출석으로 계산됩니다.

## 메뉴별 기능

### 출결 대시보드
- 차수(단위기간)별 출석률과 장려금 기준(80%)까지 남은 허용 결석일
- 전체 출석률과 수료 기준(130일 중 104일)까지 남은 출석일
- 제적 기준(결석 26일 초과)까지 남은 결석일
- 이번 차수 지각·조퇴·외출 횟수와 결석 환산 현황
- 출결 기록 목록과 유형별 필터, 차수별 출결 메모 복사(캘린더 붙여넣기용)

### 훈련장려금 확인서 발급
- 동아 AI Lab AI Agent 5기 과정운영팀 서식 이미지 위에 차수 기간, 이름, 요건 항목, 날짜, 서명을 합성해 PDF로 저장
- 마우스·터치로 전자 서명
- 기본 대상 차수는 오늘 기준 가장 최근에 끝난 차수
- 차수별 장려금 신청·승인·지급 일정 안내

### 나의 남은 휴가
- 지금까지 부여된 휴가, 사용한 휴가, 전체 남은 휴가
- 휴가 부여·이월 규칙과 신청 방법

### AI 상담 비서(출결 · 학사규정)
- 학사규정과 내 출결 데이터를 함께 보고 질문에 답하는 상담 기능
- Google Gemini 또는 Anthropic Claude 중 선택하며, **본인의 API 키**가 필요합니다
- 자주 묻는 질문 버튼 9개와 자유 질문 입력창

## 계산 규칙

| 항목 | 기준 |
|---|---|
| 장려금 | 해당 차수 출석률 80% 이상 |
| 수료 | 전체 130일 중 104일(80%) 이상 출석 |
| 제적 | 전체 결석 26일(20%) 초과, 또는 차수 출석률 50% 미만 |
| 지각·조퇴·외출 | 3회 = 결석 1일 |
| 휴가 | 차수마다 1일 부여(최대 6일), 미사용분 이월, 당겨쓰기 불가, 출석 인정 |

지각·조퇴·외출의 결석 환산은 차수와 전체를 다르게 계산합니다(동아 AI Lab AI Agent 5기 과정운영팀 답변 기준).
- **차수(장려금)**: 그 차수의 횟수만 3회당 결석 1일로 환산합니다. 남은 1~2회는 다음 차수로 넘어가지 않습니다.
- **전체(수료·제적)**: 과정 전체 횟수를 모두 더한 뒤 3회당 결석 1일로 환산합니다.
- 예: 1차 지각 2회 + 2차 지각 1회 → 1차·2차는 각각 결석 0일, 전체 결석은 1일

## 데이터 저장

- 출결 기록과 API 키는 **사용하는 브라우저 안(localStorage)에만** 저장되며 다른 곳으로 전송되지 않습니다. 단, AI 상담을 사용할 때는 질문과 출결 데이터가 선택한 AI 서비스(Google 또는 Anthropic)로 전송됩니다.
- 브라우저 데이터를 지우거나 다른 기기·브라우저로 옮기면 기록이 보이지 않습니다. 사이드바의 **백업**으로 JSON 파일을 저장하고 **복원**으로 불러오세요.
